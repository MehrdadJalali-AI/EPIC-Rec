The full `records.jsonl` files are generated by the experiment runner and are not committed: each main file is
about 80 MB. `report/tables` and `published/` are committed. They are the aggregated tables and the compact
exact-method statuses from which the manuscript numbers are written. Regenerate the tables with `epic-rec report`;
see `docs/results_schema.md` and `docs/reproducibility.md`.
